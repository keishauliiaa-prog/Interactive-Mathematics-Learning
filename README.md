# Interactive Mathematics Learning

An interactive mathematics learning application combining educational content, mathematical tools, and games to make learning mathematics easier and more engaging.

## 📌 Overview

Interactive Mathematics Learning is an educational application developed to provide a more interactive way of learning and exploring mathematics.

The application combines learning resources, mathematical calculation tools, and educational games in one platform. Users can create an account, log in, explore mathematical content, use various math tools, and practice their understanding through interactive games.

## ✨ Main Features

### 🔐 Authentication

- Sign Up
- Log In

### 📚 Browse Content

A section for exploring mathematical learning resources.

- **Mini Library**  
  A collection of mathematical learning materials.

- **Math World**  
  An interactive space for exploring mathematics and related topics.

### 🧮 Math Tool

A collection of mathematical tools designed to help users perform calculations and explore mathematical concepts.

#### Quick Math

Includes several mathematical topics and tools:

- Graphing
- Arithmetic & Functions
- Prime Numbers
- Factorials & Multiples
- Geometry & Solid Geometry
- Statistics
- Algebra
- Unit Conversion

#### Calculator

A general-purpose calculator for performing mathematical calculations.

### 🎮 Games

Interactive mathematical games designed to provide a more engaging way to practice mathematical concepts.

## 📖 Mathematical Topics

The application covers several areas of mathematics, including:

- Arithmetic
- Functions
- Algebra
- Statistics
- Geometry
- Solid Geometry
- Prime Numbers
- Factorials
- Multiples
- Unit Conversion
- Graphs

## 🛠️ Technology

- Delphi
- Object Pascal

## 🚀 How to Run

1. Clone or download this repository.
2. Open `Project1.dpr` using Delphi.
3. Make sure all project files are located in the same directory.
4. Compile and run the project.
